# AXT Intelligence - Protótipo MVP

Protótipo funcional navegável desenvolvido em HTML, CSS e JavaScript.

## Como abrir localmente
Abra o arquivo `index.html` no navegador.

## Como publicar na Vercel
1. Acesse vercel.com
2. Entre com GitHub, Google ou e-mail
3. Clique em Add New > Project
4. Faça upload/importação desta pasta
5. Clique em Deploy

Depois de publicado, use o link gerado no trabalho e também em um QR Code.


Ajustes finais: título do navegador simplificado para AXT Intelligence, favicon com símbolo da marca, login sem rolagem e botão Sair retornando para a tela de login.
